# This_year/CA1 — Neural Networks Basics

This folder contains practical notebooks, datasets and the report for CA1 of the NNDL course (fundamentals of neural networks, backpropagation, simple MLP experiments).

Quick summary:
- `code/` — primary notebooks used for experiments (e.g. `NNDL_CA1_Q1.ipynb`)
- `report/` — final writeup and results

How to run:
1. Create and activate Python environment (see top-level `README.md`).
2. From this folder run:
   ```bash
   jupyter notebook code/NNDL_CA1_Q1.ipynb
   ```
3. Use `python` scripts in `python_files/CA1_Neural_Networks_Basics/` for CLI runs.

Outputs:
- Figures are saved in `code/notebook_images/` where available.

Notes:
- This assignment uses basic PyTorch/NumPy code and synthetic datasets. No large downloads required.
