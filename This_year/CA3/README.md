# This_year/CA3 — Object Detection & Segmentation

This folder contains CA3 materials: object detection and segmentation projects including Fast-SCNN and Oriented R-CNN experiments.

Structure:
- `Fast_SCNN/` — segmentation project files, dataset info and report
- `Oriented_RCNN/` — rotated object detection implementation and writeup
- `report/` — final submission documents

How to reproduce:
- Follow README in each subfolder (e.g., `Fast_SCNN/README.md`) for data download and training steps.
- Notebooks typically live under `code/` or `codes/` and save outputs to `pictures/`.

Notes:
- Some tasks rely on external datasets and may require manual download or Kaggle access.
- See top-level `README.md` for global environment setup.
