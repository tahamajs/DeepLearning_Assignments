\subsection{Evaluation Objectives}
Evaluation is designed to answer three scientific questions:
\begin{enumerate}
  \item \textbf{VAE capacity and inference quality:} Does the modified objective/hierarchy improve latent utilization, sample quality, and likelihood-related metrics relative to a standard VAE?
  \item \textbf{Posterior collapse behavior:} How do KL dynamics, active units, and posterior statistics differ between baseline and proposed models?
  \item \textbf{Augmentation effectiveness:} Under limited data, does GAN-generated augmentation measurably improve classifier generalization on real test data?
\end{enumerate}

\subsection{VAE Metrics and Diagnostics}
\paragraph{(V1) Loss decomposition.}
We report reconstruction loss $\mathcal{L}_{\mathrm{rec}}$, KL term(s) $\mathcal{L}_{\mathrm{KL}}$ (per latent level when hierarchical), and total negative ELBO.

\paragraph{(V2) Latent activity / active units.}
We quantify latent utilization via active units, e.g.,
dimensions with $\mathrm{Var}_x[\mathbb{E}(z\mid x)]$ above a small threshold, and via per-dimension KL contributions.

\paragraph{(V3) Posterior vs prior match.}
We compare aggregate posterior statistics (means, variances, covariance structure in PCA space) to the prior (standard normal or learned mixture prior). This directly probes over-regularization and collapse-like behavior.

\paragraph{(V4) Likelihood estimation (importance sampling).}
We estimate $\log p_\theta(x)$ with an importance-weighted estimator:
\[
\widehat{\log p_\theta(x)}=
\log\left(\frac{1}{K_{\mathrm{IS}}}\sum_{k=1}^{K_{\mathrm{IS}}}
\frac{p_\theta(x\mid z^{(k)})p(z^{(k)})}{q_\phi(z^{(k)}\mid x)}\right),
\quad z^{(k)}\sim q_\phi(z\mid x).
\]
We explicitly report $K_{\mathrm{IS}}$ and use the same estimator across models for fair comparison.

\paragraph{(V5) Qualitative samples and traversals.}
We provide generated samples from $p(z)$ and latent traversals (and PCA-based traversals) to assess whether learned directions correspond to meaningful factors of variation.

\paragraph{(V6) Pseudo-input visualization.}
We visualize pseudo-inputs $\{u_k\}$ and interpret whether they represent diverse modes of the data distribution, consistent with a multimodal learned prior.

\subsection{GAN Training Metrics}
\paragraph{(G1) Critic and generator losses.}
We plot $-\mathbb{E}[D(x_{\mathrm{real}},y)]+\mathbb{E}[D(x_{\mathrm{fake}},y)]$ (Wasserstein term), total critic loss (including GP, drift, embedding regularization), and generator loss $-\mathbb{E}[D(x_{\mathrm{fake}},y)]$.

\paragraph{(G2) Regularization terms.}
We plot gradient penalty magnitude, drift penalty, and embedding regularization across training steps.

\paragraph{(G3) Fixed-noise sample grids.}
We export grids at steps $\{0,1000,2000,3000,4000\}$ using fixed noise and fixed labels to ensure comparable qualitative assessment across checkpoints.

\subsection{Augmentation Evaluation (Classifier-Based)}
\paragraph{(A1) Baseline vs augmented training.}
We train the same classifier architecture under:
\begin{itemize}
  \item real-only (limited-data) training,
  \item real + GAN-generated synthetic augmentation.
\end{itemize}
Evaluation uses the untouched FashionMNIST test set.

\paragraph{(A2) Performance reporting.}
We report:
\begin{itemize}
  \item overall test accuracy,
  \item class-wise accuracy (or per-class error rate),
  \item confusion matrix (optional but recommended for diagnosing boundary shifts).
\end{itemize}
Any improvement is interpreted in light of label-conditional sample quality and coverage, and limitations are documented when augmentation introduces class confusion.
