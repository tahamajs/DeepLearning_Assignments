\subsection{Variational Autoencoders (VAE)}
\paragraph{Latent-variable generative model.}
We model an image $x \in \mathbb{R}^{D}$ using a continuous latent variable $z \in \mathbb{R}^{d}$ with parameters $\theta$:
\[
p_\theta(x,z)=p_\theta(x\mid z)\,p(z).
\]
Learning requires the marginal likelihood $\log p_\theta(x)=\log \int p_\theta(x\mid z)p(z)\,dz$, which is generally intractable for neural decoders. We therefore introduce an amortized inference model (encoder) $q_\phi(z\mid x)$ and optimize a variational bound \citep{kingma2014vae,rezende2014stochastic}.

\paragraph{Observation model and data range conventions (critical for correctness).}
In our implementation (\texttt{deepgen/models/vae.py}), the decoder outputs $x_{\mathrm{rec}} \in (0,1)^D$ via a sigmoid. Consequently, reconstruction is evaluated with a Bernoulli/BCE-style likelihood:
\[
p_\theta(x\mid z)=\prod_{i=1}^{D}\mathrm{Bernoulli}\!\left(x_i;\,\pi_\theta(z)_i\right),\qquad \pi_\theta(z)=\sigma(f_\theta(z)).
\]
The training input $x$ is stored in $[-1,1]$ space (consistent with \texttt{Normalize(0.5,0.5)}), but BCE requires targets in $[0,1]$. Therefore, the implementation converts targets as
\[
x_{01}=\frac{x+1}{2},
\]
and uses $\mathrm{BCE}(x_{\mathrm{rec}},x_{01})$ summed over pixels (see \texttt{elbo\_loss}).

\paragraph{ELBO objective and its decomposition.}
The evidence lower bound (ELBO) satisfies:
\[
\log p_\theta(x)\ge \mathcal{L}_{\mathrm{ELBO}}(x)
=
\mathbb{E}_{q_\phi(z\mid x)}\big[\log p_\theta(x\mid z)\big]
-
\mathrm{KL}\!\left(q_\phi(z\mid x)\,\|\,p(z)\right).
\]
The first term is a reconstruction term (negative cross-entropy for Bernoulli pixels), and the KL term regularizes the approximate posterior toward the prior, controlling latent capacity and enabling sampling.

\paragraph{Encoder parameterization and the reparameterization trick.}
We take $q_\phi(z\mid x)$ to be a diagonal Gaussian:
\[
q_\phi(z\mid x)=\mathcal{N}\!\left(z;\mu_\phi(x),\mathrm{diag}(\sigma^2_\phi(x))\right),
\]
with
\[
z = \mu_\phi(x) + \sigma_\phi(x)\odot \epsilon,\qquad \epsilon \sim \mathcal{N}(0,I),
\]
which yields low-variance gradient estimates and is implemented as \texttt{reparameterize(mu, logvar)}.

\paragraph{Architecture summary (what is actually implemented).}
The VAE encoder uses a convolutional stem followed by residual blocks with optional squeeze-and-excitation (SE) gating:
\[
28\!\times\!28 \xrightarrow{\text{Conv}} 28\!\times\!28 \xrightarrow{\text{ResDown}} 14\!\times\!14 \xrightarrow{\text{ResDown}} 7\!\times\!7 \xrightarrow{\text{Res}} 7\!\times\!7 \xrightarrow{\text{FC}} (\mu,\log\sigma^2).
\]
The decoder maps $z$ through two fully-connected layers to a $7\!\times\!7$ feature map, then upsamples twice back to $28\!\times\!28$ via transposed convolutions, ending with a sigmoid output layer.

\paragraph{Flexible prior via pseudo-inputs (VampPrior) and why it matters.}
A frequent failure mode of VAEs with expressive decoders is \emph{over-regularization} toward a simplistic prior (e.g., $\mathcal{N}(0,I)$), which can yield inactive latent dimensions and posterior collapse. To increase prior flexibility, we use a VampPrior \citep{tomczak2018vampprior}:
\[
p_\lambda(z)=\frac{1}{K}\sum_{k=1}^K q_\phi(z\mid u_k),
\]
where $\{u_k\}_{k=1}^K$ are learnable pseudo-inputs. In the implementation, pseudo-inputs are direct image-shaped parameters (\texttt{self.pseudos}) and are passed through \texttt{tanh} to keep them approximately in $[-1,1]$ (consistent with the encoder's expected input range).

\paragraph{KL term with a mixture prior (how we compute it in practice).}
When $p(z)$ is a mixture defined via $q_\phi(z\mid u_k)$, the KL term is computed via Monte Carlo:
\[
\mathrm{KL}\!\left(q_\phi(z\mid x)\,\|\,p_\lambda(z)\right)
=
\mathbb{E}_{q_\phi(z\mid x)}\!\left[\log q_\phi(z\mid x) - \log p_\lambda(z)\right].
\]
The code implements:
\[
\log p_\lambda(z)=\log \frac{1}{K}\sum_{k=1}^K q_\phi(z\mid u_k)
=
\mathrm{logsumexp}_k\big(\log q_\phi(z\mid u_k)\big)-\log K,
\]
computed with numerically stable \texttt{logsumexp}. This is the central place where VampPrior increases capacity: it relaxes the mismatch between the aggregate posterior and a fixed unimodal prior.

\paragraph{$\beta$-weighting and reporting.}
For controlled latent capacity, we optionally use a $\beta$ coefficient:
\[
\mathcal{L}(x)=\mathbb{E}_{q_\phi(z\mid x)}[-\log p_\theta(x\mid z)] + \beta\cdot \mathrm{KL}\!\left(q_\phi(z\mid x)\,\|\,p_\lambda(z)\right),
\]
which matches the signature \texttt{elbo\_loss(..., beta)}. In results, we report total loss, reconstruction term, and KL term separately to diagnose whether improvements come from fidelity (recon) or representation (KL).

\paragraph{Likelihood estimation (IWAE-style).}
Because ELBO is a lower bound, we estimate $\log p_\theta(x)$ using an importance-weighted estimator \citep{burda2016iwae}:
\[
\log p_\theta(x)\approx
\log\left(\frac{1}{K}\sum_{k=1}^{K}
\frac{p_\theta(x\mid z^{(k)})\,p(z^{(k)})}{q_\phi(z^{(k)}\mid x)}\right),
\qquad z^{(k)}\sim q_\phi(z\mid x),
\]
implemented using log-space stabilization (\emph{log-mean-exp}) to avoid numerical underflow.

\paragraph{Posterior diagnostics and collapse indicators (what we report).}
We report:
(i) mean KL and distribution of per-sample KL,
(ii) active units (dimensions where $\mathrm{Var}_x[\mathbb{E}(z\mid x)]$ exceeds a threshold),
(iii) aggregate posterior statistics compared to the prior (mean/cov),
(iv) latent traversals and PCA of inferred codes.
These diagnostics are necessary because a low loss can coincide with poor latent utilization (collapse), especially in high-capacity decoders.

\subsection{Conditional GAN for Data Augmentation (WGAN-GP)}
\paragraph{Problem setting and non-overlapping splits.}
We study conditional generation on FashionMNIST under a limited-data regime. The training set is partitioned into two \emph{disjoint} subsets:
\[
\mathcal{D}_{\mathrm{GAN}} \cap \mathcal{D}_{\mathrm{CLS}}=\emptyset,
\]
where $\mathcal{D}_{\mathrm{GAN}}$ trains the generator/critic and $\mathcal{D}_{\mathrm{CLS}}$ trains the downstream classifier. This prevents a key confounder: if GAN training images overlap classifier training images, the generator can memorize examples that artificially inflate augmentation gains.

\paragraph{Conditional generator used in this implementation.}
The generator $G_\psi$ takes noise $z\sim\mathcal{N}(0,I)$ and a class label $y$ and produces $x_{\mathrm{fake}}=G_\psi(z,y)$. In \texttt{deepgen/models/gan.py}, conditioning is implemented by \emph{adding} a learned label embedding to the noise:
\[
z' = z + e_G(y),
\qquad x_{\mathrm{fake}} = G_\psi(z',y).
\]
This is a simple and effective conditioning mechanism when embedding dimension equals $z$ dimension. The generator maps $z'$ through a fully-connected layer to a $7\times 7$ feature map, upsamples to $14\times 14$, applies self-attention, upsamples to $28\times 28$, and outputs an image with $\tanh$ so that $x_{\mathrm{fake}}\in[-1,1]$.

\paragraph{Projection discriminator (conditional critic).}
The critic $D_\omega(x,y)$ is a projection discriminator \citep{miyato2018projection}. Let $h_\omega(x)\in\mathbb{R}^{d_f}$ be pooled features. The conditional score is
\[
D_\omega(x,y)=s_\omega(h_\omega(x)) + \langle h_\omega(x), e_D(y)\rangle,
\]
which enforces class-conditional discrimination without concatenating labels to image channels. The implementation uses global sum pooling (sum over spatial locations) to form $h_\omega(x)$ and then adds the projection term.

\paragraph{Spectral normalization and its role.}
To stabilize adversarial optimization, we apply spectral normalization (SN) to discriminator and generator layers \citep{miyato2018sn}:
\[
\bar{W}=\frac{W}{\sigma_{\max}(W)}.
\]
SN controls operator norms and improves stability; empirically it reduces exploding critic gradients and can reduce sensitivity to learning-rate choices.

\paragraph{Attention mechanisms included in the architecture.}
We incorporate:
(i) self-attention (SAGAN-style) to capture long-range dependencies \citep{zhang2019sagan}, and
(ii) channel attention (SE-style) to recalibrate channel responses \citep{hu2018senet}.
Both are implemented as residual modules. Self-attention computes an $HW\times HW$ attention matrix to aggregate global context; SE uses global average pooling followed by a bottleneck MLP and a sigmoid gate to modulate channels.

\paragraph{WGAN-GP objective and regularization terms.}
We adopt WGAN-GP \citep{gulrajani2017improved}. The critic estimates a Wasserstein difference:
\[
\mathcal{W}\approx \mathbb{E}[D(x_{\mathrm{real}},y)]-\mathbb{E}[D(x_{\mathrm{fake}},y)].
\]
The 1-Lipschitz constraint is enforced via gradient penalty on interpolated samples $\hat{x}$:
\[
\hat{x}=\epsilon x_{\mathrm{real}} + (1-\epsilon)x_{\mathrm{fake}},
\qquad \epsilon\sim\mathcal{U}(0,1),
\]
\[
\mathcal{L}_{\mathrm{GP}}=\lambda_{\mathrm{GP}}\,
\mathbb{E}_{\hat{x}}\left(\left\|\nabla_{\hat{x}}D(\hat{x},y)\right\|_2-1\right)^2.
\]
The implementation also includes:
(i) a drift penalty to prevent critic output drift,
\[
\mathcal{L}_{\mathrm{drift}}=\epsilon_{\mathrm{drift}}\,\mathbb{E}\left[D(x_{\mathrm{real}},y)^2\right],
\]
and (ii) embedding weight decay / regularization,
\[
\mathcal{L}_{\mathrm{emb}}=\lambda_{\mathrm{emb}}\|e_D\|_2^2.
\]
Thus, the critic loss minimized in training is:
\[
\mathcal{L}_D=
-\Big(\mathbb{E}[D(x_{\mathrm{real}},y)]-\mathbb{E}[D(x_{\mathrm{fake}},y)]\Big)
+\mathcal{L}_{\mathrm{GP}}+\mathcal{L}_{\mathrm{drift}}+\mathcal{L}_{\mathrm{emb}},
\]
and the generator loss is:
\[
\mathcal{L}_G=-\mathbb{E}[D(x_{\mathrm{fake}},y)].
\]

\paragraph{Optimization protocol and logging.}
We use Adam with assignment hyperparameters and update the critic $N_{\mathrm{critic}}$ times per generator step. During critic updates, fake samples are detached to avoid unnecessary generator gradient computation. At each logging step we record:
Wasserstein estimate, gradient penalty magnitude, drift term, embedding regularization, total losses, and fixed-noise sample grids for qualitative monitoring.

\paragraph{Augmentation evaluation (what constitutes valid evidence).}
To evaluate whether synthetic data improves generalization, we train a classifier in two regimes:
(i) real-only using $\mathcal{D}_{\mathrm{CLS}}$, and
(ii) real+synthetic using $\mathcal{D}_{\mathrm{CLS}}$ plus a controlled number of generated samples per class.
Final evaluation is performed \emph{only} on the untouched FashionMNIST test set (real samples). We report overall accuracy, class-wise accuracy, and confusion patterns. Any improvement must be interpreted jointly with generator diagnostics (fixed-noise grids and critic statistics) to distinguish genuine distributional expansion from mode-dropping artifacts.
