\subsection{Environment Specification}
For exact reproducibility, record:
\begin{itemize}
  \item OS and hardware (CPU model, RAM; GPU if used),
  \item Python version,
  \item OpenCV version and build (CPU/GPU),
  \item dependency lock file (\texttt{requirements.txt}).
\end{itemize}

\subsection{Determinism Controls}
Even classical CV pipelines can show small nondeterminism due to threading and internal heuristics. Recommended controls:
\begin{itemize}
  \item set fixed random seeds in Python and NumPy,
  \item set OpenCV thread count to a fixed value,
  \item log all parameter values to \texttt{config.json}.
\end{itemize}

\subsection{Reproducible Command Lines}
The report should list the exact commands used to generate results, including:
\begin{itemize}
  \item data paths,
  \item output directory,
  \item config file path,
  \item evaluation thresholds.
\end{itemize}
A scientifically complete artifact includes the exported metrics CSVs and all report figures placed under \texttt{../results/figures/}.
