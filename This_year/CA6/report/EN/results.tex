\subsection{Quantitative Summary}
If you export a summary CSV (recommended), it can be included directly:

\SafeCSVTable{../results/metrics/summary.csv}{Summary metrics exported by the evaluation script (example filename: \texttt{summary.csv}).}{tab:summary_metrics}

\paragraph{How to interpret the summary table scientifically.}
The summary table should contain (at minimum) dataset-level aggregates:
\begin{itemize}
  \item \textbf{Mean reprojection error (MRE):} lower is better; reflects average geometric alignment quality in pixel units.
  \item \textbf{Median reprojection error (MedRE):} robust central tendency; if MedRE $\ll$ MRE, failures/outliers likely exist.
  \item \textbf{Success rate at threshold $\delta$:} operationally interpretable; reports fraction of images meeting tolerance.
  \item \textbf{Runtime (ms) and FPS:} feasibility for interactive or near-real-time use.
\end{itemize}

\subsection{Qualitative Results: Overlay Inspection}
% \ResultGraphic{../results/figures/overlay_grid.png}{0.95\linewidth}{Representative overlays: the warped template projected onto query photographs. Generated by the evaluation script.}

\paragraph{What this figure demonstrates.}
The overlay grid is the primary qualitative validation:
\begin{itemize}
  \item Correct alignment is indicated when template edges, holes, contours, or printed markings coincide with the photographed part boundaries.
  \item Local misalignment (e.g., drift near corners) often signals either (i) insufficient inliers for stable estimation, (ii) non-planarity, or (iii) systematic preprocessing mismatch (scale/rotation or contrast issues).
  \item If overlays are consistently offset in the same direction across the dataset, the issue is typically deterministic (e.g., incorrect resizing conventions, template standardization mismatch, or coordinate-frame assumptions).
\end{itemize}

\paragraph{Operational conclusion from overlays.}
If the overlays show consistent edge coincidence on most samples, the system is suitable for visual inspection tasks. If overlays are only intermittently correct, the method may still be viable with mitigation (ROI restriction, stricter match filtering, or improved template contrast).

\subsection{Alignment Error Distribution}
% \ResultGraphic{../results/figures/reproj_error_hist.png}{0.85\linewidth}{Distribution of per-image mean reprojection error (pixels).}

\paragraph{What the error histogram demonstrates.}
The error histogram provides statistical evidence of robustness:
\begin{itemize}
  \item A \textbf{tight, unimodal} distribution concentrated near low errors indicates stable geometric estimation.
  \item A \textbf{heavy tail} indicates occasional failures (catastrophic misalignment) that can dominate the mean.
  \item A \textbf{bimodal} shape often indicates two regimes: (i) correct alignment cases and (ii) systematic failure cases (e.g., glare or repetitive texture).
\end{itemize}

\paragraph{Scientific interpretation of MRE vs.\ MedRE.}
\begin{itemize}
  \item If MedRE remains low while MRE increases, outlier failures exist; reporting success rate at a tolerance threshold becomes essential.
  \item If both MedRE and MRE are high, the method is generally inaccurate under the tested conditions, implying the need to revisit assumptions (planarity), features, or preprocessing.
\end{itemize}

\subsection{Runtime and Stage-Wise Profiling}
% \ResultGraphic{../results/figures/runtime_breakdown.png}{0.9\linewidth}{Runtime breakdown across pipeline stages (feature extraction, matching, RANSAC, warp).}

\paragraph{What runtime breakdown demonstrates.}
Runtime profiling isolates bottlenecks:
\begin{itemize}
  \item If feature extraction dominates, reducing resolution or ORB \texttt{nfeatures} can reduce latency.
  \item If matching dominates, more aggressive pre-filtering or approximate matching strategies may be needed.
  \item If RANSAC dominates, inlier ratios may be low (forcing more iterations), suggesting better match filtering or ROI gating.
\end{itemize}

\paragraph{Deployment feasibility statement.}
The system is feasible for deployment when the measured median latency satisfies the operational constraint, and when latency variance is not dominated by rare pathological cases. For scientifically credible claims, report median and 95th percentile runtime, not only the mean.

\subsection{Ablation Study: Parameter Sensitivity}
% \ResultGraphic{../results/figures/ablation_plot.png}{0.9\linewidth}{Ablation: alignment quality and success rate vs.\ key parameters (e.g., ORB \texttt{nfeatures}, RANSAC threshold $\tau$, match filtering).}

\paragraph{What the ablation plot demonstrates.}
Ablations identify stable operating regions:
\begin{itemize}
  \item Increasing \texttt{nfeatures} usually increases inliers and stability up to a point, after which additional features can add noise and slow runtime.
  \item Increasing $\tau$ (RANSAC reprojection threshold) increases inlier acceptance but can degrade precision if too permissive.
  \item Cross-check generally reduces false matches at the cost of fewer correspondences; it is beneficial when clutter is high.
\end{itemize}

\paragraph{Scientific conclusion from ablations.}
A robust configuration is one where:
\begin{itemize}
  \item success rate plateaus at a high value (insensitive to small parameter changes),
  \item error remains low without requiring extreme parameter tuning,
  \item runtime remains within constraints.
\end{itemize}
The goal is not maximal performance on one setting, but stability under realistic variation.

\subsection{Failure-Case Analysis and Diagnostics}

\paragraph{What failure figures demonstrate.}
Failure-case figures provide boundary conditions for validity:
\begin{itemize}
  \item \textbf{Repetitive patterns:} can produce geometrically consistent but incorrect homographies if matches cluster on repeated motifs.
  \item \textbf{Glare/low contrast:} reduces feature repeatability, leading to too few inliers or unstable transforms.
  \item \textbf{Occlusion or truncation:} reduces overlap between template and photo, lowering inlier count below what RANSAC needs.
\end{itemize}

\paragraph{Scientifically justified mitigations (activated only if supported by measured improvements).}
\begin{itemize}
  \item ROI gating using a detector/segmentation mask to suppress background matches.
  \item More stringent match filtering (distance percentile, additional geometric sanity checks).
  \item Improved illumination normalization (e.g., CLAHE in grayscale) when glare/contrast is the dominant failure driver.
\end{itemize}

\subsection{Result Summary: What the Results Prove}
Collectively, the exported results support three claims:
\begin{enumerate}
  \item \textbf{Geometric correctness:} supported by low reprojection error and visually correct overlays on representative samples.
  \item \textbf{Robustness characteristics:} supported by error distributions (tail behavior) and ablation stability regions.
  \item \textbf{Feasibility:} supported by runtime and bottleneck identification.
\end{enumerate}
