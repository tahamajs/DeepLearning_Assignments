\subsection{هدف پیش‌پردازش}
پیش‌پردازش برای کاهش تغییرپذیری‌های غیرضروری و افزایش تکرارپذیری ویژگی‌ها انجام می‌شود:
\begin{itemize}
  \item کنترل مقیاس تصویر برای پایداری زمان اجرا،
  \item تبدیل به خاکستری برای استخراج ویژگی،
  \item در صورت نیاز، بهبود کنتراست محلی برای بافت کم یا نور نامناسب.
\end{itemize}

\subsection{گام‌های استاندارد}
برای هر تصویر $\mathcal{I}$:
\begin{enumerate}
  \item تغییر اندازه به‌گونه‌ای که $\max(\text{عرض},\text{ارتفاع}) \le M$ پیکسل باشد.
  \item تبدیل به تصویر خاکستری.
  \item اختیاری: اعمال CLAHE برای افزایش کنتراست محلی در شرایط نور نامطلوب.
\end{enumerate}

\subsection{توجیه علمی}
ویژگی‌های محلی بر پایهٔ گرادیان و ساختار موضعی کار می‌کنند. کوچک‌سازی بیش از حد باعث از دست رفتن جزئیات و کاهش نقاط کلیدی می‌شود، و بزرگ نگه‌داشتن تصویر زمان اجرا را بدون سود متناسب افزایش می‌دهد. بنابراین $M$ و سیاست تغییر اندازه باید به‌عنوان پارامتر آزمایشی ثبت و گزارش شوند.
