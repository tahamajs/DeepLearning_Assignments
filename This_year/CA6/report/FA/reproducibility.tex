\subsection{مشخصات محیط اجرا}
برای بازتولید دقیق نتایج، باید موارد زیر ثبت شوند:
\begin{itemize}
  \item سیستم‌عامل و سخت‌افزار (CPU، RAM و در صورت وجود GPU)،
  \item نسخه Python،
  \item نسخه OpenCV و نحوهٔ نصب،
  \item فایل وابستگی‌ها (\texttt{requirements.txt}).
\end{itemize}

\subsection{کنترل عدم‌قطعیت (Determinism)}
حتی در روش‌های کلاسیک، برخی منابع عدم‌قطعیت ممکن است وجود داشته باشد (چندریسمانی و ...). توصیه می‌شود:
\begin{itemize}
  \item Seed ثابت برای Python و NumPy تنظیم شود،
  \item تعداد Threadهای OpenCV ثابت شود،
  \item تمام پارامترها در \texttt{config.json} ذخیره شوند.
\end{itemize}

\subsection{ثبت فرمان‌های اجرا}
برای شفافیت علمی، فرمان‌های اجرا (مسیر داده، مسیر خروجی، مسیر تنظیمات) باید در پیوست ذکر شوند تا هر شخص دیگری بتواند همان خروجی‌ها را تولید کند.
