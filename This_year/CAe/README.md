# This_year/CAe — Elective & Extra Exercises

This folder contains elective assignments and extra exercises for the course (audio, adversarial, image captioning variants, etc.).

Structure:
- `codes/` — modular scripts, notebooks and helper utilities
- `report/` — writeups and results

How to reproduce:
- Check the README files inside `codes/` for Q1/Q2/Q4 specific instructions (many subfolders have their own `README.md`).

Notes:
- Exercises in this folder often touch on more advanced topics and use specialized packages (e.g., `librosa` for audio). Review the `requirements.txt` before running.
