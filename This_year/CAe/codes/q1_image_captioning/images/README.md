This folder stores all images and exported assets for the Q1 Image Captioning demo and experiments.

Naming convention:
- fig-<section>-<metric>-<desc>-<timestamp>.<ext>

Example assets created by the demo notebook:
- `fig-captioning-length-hist-YYYYMMDD-HHMMSS.png`  (Caption length histogram)
- `q1_sample_image_01_cat.png`  (Sample synthetic image)
- `q1_generated_caption_sample_01.png`  (Image with rendered caption)
- `manifest.csv`  (List of saved assets with metadata)
- `table-sample-captions.csv` and `.tex`  (Sample table exports)

Use these high-resolution PNGs and PDFs (if generated) directly in your IEEE manuscript figures.
