\section{Related Work}
A concise overview of related technical literature:
\textbf{Image captioning:} The encoder-decoder paradigm with attention was popularized by Show-Attend-and-Tell \cite{xu2015show}. Subsequent works incorporate diverse attention styles and reinforcement learning objectives for captioning.

\textbf{Contrastive multimodal learning:} CLIP \cite{radford2021learning} introduced a scalable contrastive approach to align image and text representations using InfoNCE loss and text prompts for zero-shot classification.

\textbf{Audio self-supervision:} Wav2Vec 2.0 \cite{baevski2020wav2vec} and HuBERT \cite{hsu2021hubert} demonstrate powerful pretraining for downstream audio tasks.

\textbf{Parameter-efficient fine-tuning:} LoRA \cite{hu2021lora} reduces trainable parameters by inserting low-rank adaptors into large models, enabling efficient fine-tuning.

\textbf{Adversarial robustness:} FGSM \cite{goodfellow2014explaining} and PGD (Madry et al.) \cite{madry2017towards} are widely-studied attack methods; adversarial training is an effective defense strategy with known trade-offs.

\section{Q1: Image Captioning}\label{sec:q1}
This section details the problem formulation, preprocessing, model architecture, training, and evaluation.

\subsection{Problem formulation}
Given image $I$, generate a caption $S=(w_1,\dots,w_T)$ maximizing $P(S|I)$. We model
\begin{equation}
P(S|I)=\prod_{t=1}^{T} P(w_t|I,w_{<t}).
\end{equation}
Training minimizes negative log-likelihood with teacher forcing.

\subsection{Data and preprocessing}
Dataset: Flickr/COCO subset (images + Persian captions) supplied with the assignment. Steps:
\begin{enumerate}
  \item Normalization: Unicode normalization and lowercasing.
  \item Cleaning: remove punctuation, preserve emojis, trim whitespace.
  \item Tokenization: whitespace-based tokens; optional subword (BPE) extension available.
  \item Vocabulary: built on training captions; include \texttt{<start>, <end>, <pad>, <unk>}.
\end{enumerate}
We also compute statistics: caption lengths (min, max, mean, median), unique token counts, and the frequency distribution for OOV analysis. Figures are saved as `fig-captioning-length-hist-*.png/pdf`.

\subsection{Model architecture}
\textbf{Encoder:} Pretrained VGG16 features (conv layers) with an adaptive pooling layer to produce a fixed-size spatial feature map $F\in \mathbb{R}^{H\times W\times C}$. We flatten to $A=[a_1,\ldots,a_L], a_i\in\mathbb{R}^D$ where $L=H\cdot W$.

\textbf{Attention:} Additive attention calculates scores:
\begin{align}
 e_{t,i} &= v^\top \tanh(W_a a_i + U_a h_{t-1} + b_a), \\
 \alpha_{t,i} &= \frac{\exp(e_{t,i})}{\sum_j \exp(e_{t,j})}, \\
 c_t &= \sum_i \alpha_{t,i} a_i.
\end{align}

\textbf{Decoder:} LSTMCell takes input $x_t = [E(w_{t-1}); c_t]$, updates $(h_t,c_t)$ and outputs logits via $o_t=\mathrm{softmax}(W_o h_t + b_o)$. Embedding dimension: 300; hidden dim: 512. We initialize $h_0,c_0$ to zeros and optionally learn a projection from encoder pooled features.

\subsection{Training procedure}
Loss: masked cross-entropy ignoring padding tokens:
\begin{equation}
\mathcal{L}= -\sum_{i\in \text{batch}} \sum_{t=1}^{T_i} \log P(w_t^{(i)} | I^{(i)}, w_{<t}^{(i)}).
\end{equation}
Teacher forcing probability is configurable; by default we use full teacher forcing for smoke runs. Optimization: AdamW with weight decay, learning-rate scheduling, and early stopping by validation loss.

\subsection{Inference}
Greedy decoding is used for baseline generation. Beam search (width 3--5) is implemented and available as an option; we note empirical gains in BLEU for higher-quality beam search outputs.

\subsection{Evaluation}
We evaluate using sacreBLEU (BLEU-1..4) for reproducibility and present qualitative examples (GT vs generated). BLEU formula and brevity penalty are computed as in \cite{papineni2002bleu}.

\section{CLIP-style Contrastive Learning}\label{sec:clip}
\subsection{Model}
The image encoder is a ViT from `timm` (e.g., vit\_small\_patch16\_224) with a projection head: $z_{img}=\mathrm{proj}(f_{vit}(I))$. The text encoder is a lightweight LSTM or small Transformer producing $z_{txt}=\mathrm{proj}(g_{txt}(S))$. Both outputs are L2-normalized.

\subsection{InfoNCE and Temperature}
For a batch of $N$ pairs we compute similarities $s_{ij}=z_{img,i}^\top z_{txt,j}/\tau$, where $\tau$ is a learned scalar temperature. The symmetric loss is the average cross-entropy when matching images to text and text to images \cite{radford2021learning}.

\subsection{Zero-shot and retrieval}
We evaluate retrieval (text->image and image->text) using recall@k (k=1,5,10). For small-scale tests we report recall on held-out sets; larger-scale evaluation is possible when dataset sizes permit.

\section{Q2: UrbanSound — Audio Classification}\label{sec:q2}
\subsection{Dataset specifics}
UrbanSound8K metadata is processed to create train/val/test splits (80/10/10). Each clip is resampled to 16 kHz and normalized. We compute mel-spectrograms (64 mel bins, 25 ms window, 10 ms hop, Hamming window) to serve as CNN input. Data augmentation: time-shift, additive noise, random gain; we also implement SpecAugment-style masking as an option.

\subsection{Models and training regimes}
We compare:
\begin{itemize}
  \item CNN trained from scratch on mel-spectrograms.
  \item Wav2Vec2-based model with a classification head (three regimes: freeze, partial, full fine-tuning).
\end{itemize}
Training uses AdamW, learning-rate scheduling, and early stopping. We log per-epoch accuracy and loss and save confusion matrices and per-class precision/recall for analysis.

\subsection{Observations}
Pretrained Wav2Vec representations provide strong transfer with limited labeled data. Partial fine-tuning often strikes a balance between stability and task-specific adaptation.

\section{Q3: LoRA Fine-Tuning}\label{sec:q3}
\subsection{LoRA formulation}
For target weight $W_0\in \mathbb{R}^{d\times k}$ (e.g., query projection), LoRA parameterizes updates as $W=W_0 + BA$ with $B\in\mathbb{R}^{d\times r}, A\in\mathbb{R}^{r\times k}$, where $r\ll \min(d,k)$. During training only $A$ and $B$ (and optionally layer norms) are updated, enabling efficient adaptation.

\subsection{Prompting and evaluation}
We format classification prompts using the course-specified instruction template and fine-tune using LoRA with $r=8, \alpha=32,\mathrm{dropout}=0.1$. Evaluation metrics are classification accuracy and macro-F1; we also provide confusion matrices and sample model outputs.

\section{Q4: Adversarial Attacks and Training}\label{sec:q4}
\subsection{FGSM and PGD}
FGSM (one-step): $x' = x + \epsilon \cdot \mathrm{sign}(\nabla_x \mathcal{L})$. PGD (multi-step) iteratively applies small perturbations and projects back into the allowed $\ell_\infty$ ball. We analyze the effects of $\epsilon$ and number of iterations $T$ on robustness.

\subsection{Adversarial training strategy}
We implement on-the-fly PGD adversarial generation during training and compare models trained on clean data, FGSM-augmented data, and PGD-augmented data. We measure robust accuracy under a range of attacks and plot accuracy vs $\epsilon$ curves.

PGD training pseudocode (single batch):
\begin{algorithm}
\caption{PGD adversarial training single-batch inner loop}
\begin{algorithmic}[1]
\State Input batch $(x,y)$, model $\theta$, steps $T$, step-size $\alpha$, eps $\epsilon$
\State $x_{adv} \leftarrow x$
\For{$t=1\dots T$}
  \State $g \leftarrow \nabla_x \mathcal{L}(\theta, x_{adv}, y)$
  \State $x_{adv} \leftarrow \Pi_{\|\cdot - x\|_\infty \le \epsilon}(x_{adv} + \alpha \cdot \mathrm{sign}(g))$
\EndFor
\State Update $\theta$ with loss $\mathcal{L}(\theta, x_{adv}, y)$
\end{algorithmic}
\end{algorithm}

\section{Q1: Image Captioning}
\subsection{Data and Preprocessing}
We use a provided Flickr/COCO subset that includes images and Persian captions. Preprocessing removes punctuation, lowercases text, and separates emojis where applicable. We build a vocabulary from training captions and add four special tokens: \texttt{<start>} (sos) used to signal the start of generation, \texttt{<end>} (eos) to terminate sequences, \texttt{<pad>} used for batch padding, and \texttt{<unk>} to represent out-of-vocabulary tokens.

Tokenization: The provided `Tokenizer` class converts sentences to index sequences and handles punctuation/emoji. We save the tokenizer for inference and reproducibility.

\subsection{Model Architecture}
Encoder: We use a pretrained VGG16 (ImageNet) and remove classification heads, keeping convolutional features. The output feature vector is projected to a 512-dim vector and optionally spatial-pooled to support attention.

Decoder: Our decoder is an LSTMCell-based model with an additive attention mechanism (Bahdanau-style). At each timestep the attention module computes alignment weights between the decoder hidden state and encoder features, producing an attention-weighted encoding concatenated with the input embedding.

The decoder uses embedding size 300 and hidden size 512. Teacher forcing is used in training, where the ground-truth token is provided as input to the next timestep; during inference we perform greedy decoding (top-1) until the \texttt{<end>} token.

\subsection{Training Details and Hyperparameters}
Training uses Cross-Entropy loss (ignoring padding indices). We freeze the encoder feature extractor to accelerate initial experiments and train only the decoder and the projection layer. For smoke runs, we train for a few epochs; for full experiments we recommend at least 30 epochs with early stopping by validation loss.

Representative hyperparameters used in experiments (see Appendix~\ref{appendix:hyper}): learning rate = 1e-3 (AdamW), batch size = 64 (or 32 if memory limited), embedding dim = 300, hidden dim = 512, weight decay = 1e-5.

\subsection{Evaluation}
We evaluate with BLEU-1..4 lexical metrics \cite{papineni2002bleu, post-2018-call} and also produce qualitative samples. BLEU is computed with sacreBLEU for reproducibility. For retrieval-style evaluation (CLIP-style) we compute recall@k when applicable.

\section{Q1.5: CLIP-style Contrastive Learning (Image-Text)}
\subsection{Model and Loss}
Image encoder: a ViT backbone (e.g., `vit_small_patch16_224` from `timm`) with an MLP projection to an embedding dimension (e.g., 256) followed by L2 normalization. Text encoder: a small LSTM or Transformer that outputs a fixed-length vector projected to the same embedding size and normalized. The InfoNCE loss is computed on a batch: for correct pairs similarity is maximized, and incorrect pairs minimized, with logits scaled by a learnable temperature parameter $\tau$.

\subsection{Zero-shot and Retrieval}
We demonstrate zero-shot retrieval by querying with text prompts and ranking images by cosine similarity, reporting Top-1 and Top-5 accuracies on held-out samples.

\section{Q2: Urban Sound Classification}
\subsection{Dataset and Preprocessing}
UrbanSound8K is a standard dataset of 8,732 labeled audio clips categorized into 10 classes. We preprocess waveforms (resampling to 16kHz) and compute mel-spectrograms with 64 mel-bins for CNN training. For Wav2Vec experiments, we feed raw audio to the pretrained backbone and extract features or fine-tune.

\subsection{Models and Experimental Regimes}
We run three experimental regimes with Wav2Vec:
\begin{itemize}
    \item Freeze All: Freeze backbone, train only classification head.
    \item Partial Freeze: Freeze first 6 transformer layers, fine-tune the rest.
    \item Full Fine-Tuning: Unfreeze entire model and train end-to-end (requires strong regularization and careful LR scheduling).
\end{itemize}

We compare these to a baseline CNN trained from scratch on mel-spectrograms.

\subsection{Metrics and Analysis}
We report classification accuracy, macro-F1, and confusion matrices. Convergence speed and sample efficiency are discussed: transfer learning from Wav2Vec is generally more sample-efficient than training a CNN from scratch.

\section{Q3: LoRA Fine-tuning for Sentiment Analysis}
LoRA inserts low-rank adaptation matrices into selected modules (e.g., query/key/value projection matrices). This allows training a small number of parameters while keeping the large model weights frozen. We fine-tune `meta-llama/Llama-3.2-1B` on a stratified subset of the Emotion dataset (train=1500, val=50, test=100) and report accuracy and macro-F1. Methods for prompt formatting, tokenization, and evaluation scripts are included in `codes/q3_lora`.

\section{Q4: Adversarial Attacks and Adversarial Training}
\subsection{Attack Algorithms}
FGSM (Fast Gradient Sign Method) perturbs inputs in the direction of the sign of the gradient of loss w.r.t input (one-step). PGD (Projected Gradient Descent) performs iterative perturbations constrained to an $\ell_\infty$ ball of radius $\epsilon$, with step size $\alpha$ and $T$ iterations. We implement both and evaluate their effect on model accuracy.

\subsection{Adversarial Training}
We implement adversarial training by generating PGD adversarial examples on-the-fly during each training batch and training on a mixture of clean and adversarial images. We report robust accuracy and compare trade-offs between clean accuracy and robustness.

\section{Results and Discussion}
Due to compute constraints, this report includes smoke-run quantitative results and detailed reproducible instructions to reproduce full experiments on GPU-equipped machines. Figures and tables in the `codes/*/images/ieee_assets/` directories are high-resolution and LaTeX-ready.

Our qualitative observations:
\begin{itemize}
    \item Attention-based captioning produces fluent captions for simple scenes but struggles with fine-grained object relations in low-data regimes.
    \item CLIP-style contrastive pretraining yields robust image-text embeddings and supports zero-shot retrieval with reasonable top-k recall in our small-scale experiments.
    \item Wav2Vec transfer dramatically improves sample efficiency on UrbanSound compared to CNNs trained from scratch when labeled data is limited.
    \item LoRA provides an effective, storage-efficient way of fine-tuning large LLMs for classification tasks with limited resources.
    \item Adversarial training improves robustness at the cost of some clean accuracy; PGD-trained models generalize better against multiple attack strengths compared to FGSM-only training.
\end{itemize}
